🛡️

Zero-Leakage Privacy Firewall

Deterministic regex and entropy checks block AWS keys, JWTs, private SSH keys, and SSNs. Sensitive queries are mathematically locked to local SLMs and never leaked to cloud APIs.

⚡️

Sub-10ms Semantic Scorer

Combines structural entropy, reasoning keyword detectors, and normalized centroid archetype cosine similarity to classify queries with near-zero latency and no GPU overhead for the router.

🔄

Automated Fallback & Circuit Breakers

Monitors hardware saturation, connection timeouts, and degenerate repetition loops. If local hardware saturates or SLMs stutter, EdgeCascade gracefully cascades upward.

🔌

Drop-in OpenAI Compatibility

Exposes standard /v1/chat/completions with streaming SSE. Compatible with Cursor, Continue, Cline, Open WebUI, and standard OpenAI SDKs by changing base_url.

💰

Cost Savings Analytics

Tracks token savings against frontier cloud benchmark models (GPT-4o / Claude 3.5 Sonnet) in real-time, providing Prometheus metrics and interactive dashboard telemetry.

🚀

Unified Multi-Provider Adapters

Seamless native adapters for Ollama, vLLM, OpenAI, Anthropic Claude, and Google Gemini with connection pooling and unified token streaming.
